# UI 디자인 가이드

이 문서는 UI 구현 시 참고할 색상, 타이포그래피, 레이아웃 및 컴포넌트 규칙을 정의합니다.

## 1. 색상

### 기본 색상

| 이름 | HEX 코드 | 사용 용도 |
| --- | --- | --- |
| 메인 포인트 청록·초록 | `#009B87` | 주요 버튼, 선택 체크, 선택된 아이콘, 진행 바 |
| 연한 민트 | `#EAF8F3` | 선택 항목 배경, 추천 결과 카드 배경 |
| 진한 차콜 | `#202C30` | 제목, 본문, 금액, 어두운 버튼 배경 |
| 보조 회색 | `#778286` | 설명, 항목 이름, 보조 정보 |
| 따뜻한 연회색 | `#F6F5F1` | 안내 영역 배경 |
| 구분선 회색 | `#E6E8E4` | 구분선, 진행 바의 미완료 구간 |
| 오류 빨강 | `#B94737` | 입력 오류, 예산 초과 안내 |
| 흰색 | `#FFFFFF` | 화면 배경, 입력 폼 배경, 버튼 글자 |

### 보조 색상

| 이름 | HEX 코드 | 사용 용도 |
| --- | --- | --- |
| 웹 외부 배경 | `#E9EFEC` | 웹에서 모바일 화면 바깥 배경 |
| 미선택 체크 테두리 | `#AFB7B2` | 선택 전 체크 원의 테두리 |
| 카테고리 아이콘 배경 | `#F4F6F5` | 카테고리 아이콘 배경 |
| 글꼴 로딩 스피너 | `#008B78` | 글꼴 로딩 스피너 전용 색상 |

> 글꼴 로딩 스피너에는 메인 포인트 색상 `#009B87`과 구분되는 별도 값 `#008B78`을 사용합니다.

## 2. 타이포그래피

### 글꼴 및 굵기

| 글꼴 | 적용 대상 |
| --- | --- |
| Hana2 Regular | 본문, 설명 |
| Hana2 Medium | 강조 텍스트, 버튼 |
| Hana2 Bold | 제목, 금액 |

### 글자 크기

| 적용 대상 | 크기 |
| --- | --- |
| 설명 | `13dp` |
| 본문·버튼 | `16dp` |
| 기본 제목 | `28dp` |
| 핵심 금액 | `38dp` |

## 3. 화면 레이아웃

| 항목 | 규칙 |
| --- | --- |
| 모바일 화면 최대 폭 | `430dp` |
| 본문 좌우 여백 | 각각 `22dp` |
| 웹에서 모바일 화면 바깥 배경 | `#E9EFEC` |

## 4. 컴포넌트

### 버튼

| 항목 | 규칙 |
| --- | --- |
| 최소 높이 | `56dp` |
| 모서리 반경 | `12dp` |
| 주요 버튼 배경 | `#009B87` |
| 어두운 버튼 배경 | `#202C30` |
| 버튼 글자 색상 | `#FFFFFF` |
| 글꼴 | Hana2 Medium |
| 글자 크기 | `16dp` |

### 추천 카드

| 항목 | 규칙 |
| --- | --- |
| 배경 색상 | `#EAF8F3` |
| 모서리 반경 | `22dp` |
| 내부 여백 | `20dp` |
| 그림자 | 사용하지 않음 |
| 떠오르는 효과 | 사용하지 않음 |

### 비활성 상태

- 비활성 상태에는 불투명도 `0.4`를 적용합니다.

## 5. AI 구현 참고 사항

- 색상은 사용 용도에 맞는 정확한 HEX 값을 사용합니다.
- 글꼴의 굵기와 크기는 각각 지정된 적용 대상을 따릅니다.
- 최소 높이와 최대 폭은 고정 크기가 아닌 제한값으로 적용합니다.
- 추천 카드에는 그림자나 떠오르는 효과를 추가하지 않습니다.
- 이 문서의 크기 단위는 `dp`입니다. 구현 환경에서 다른 단위를 사용하는 경우 변환 기준을 명시합니다.
- 문서에 정의되지 않은 디자인 값은 기존 규칙과 구분하여 제안합니다.
