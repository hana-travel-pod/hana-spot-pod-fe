당신은 숙련된 프론트엔드 개발자 입니다. 아래는 현재 기능에 대한 추가 개발 사항입니다.


1. 개발 제한
데모성으로 제작하는 것이기에 개발은 간단하게 진행해주세요.
모바일에서 사용함.
React Native + Expo + TypeScript 조합으로 개발을 진행해줘.

2. 추가 개발 사항
* 참가를 확정한 모임을 확인하는 기능이 있으면 좋겠어. 지금은 '가입한 팟'에 대한 숫자만 나오지만 이것의 목록도 확인하면 좋겠어.
* 자동 가입 승인이 되었으면 좋겠어. 현재는 가입을 신청하면 모임장이 승인해야하는 구조지만 데모인 만큼 자동으로 승인 처리가 되면 좋겠습니다.
* 모임을 만들 때, 그리고 신청할 때, 조건들을 필수로 입력, 선택하지 않아도 되게 해주세요. 지금은 무조건 모든 항목을 필수로 체크해야하는데 그게 불편합니다.
* 여행 시작일, 여행 종료일을 지정할 때, 날짜를 직접 입력하지 않더라도 간단하게 선택하는 것만으로도 입력이 완료되게 해주세요.
