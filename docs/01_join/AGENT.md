1. 개발 제한
모바일에서 사용함.
React Native + Expo + TypeScript 조합으로 개발을 진행해줘.

1.1. 기능: 여행 팟 생성
여행 일정·예산·참여 조건을 바탕으로 모임을 만들고, 자신에게 맞는 여행 팟을 찾아 참가하는 기능

① 개설자 — 여행 조건 설정 및 모집
개설자는 몇가지 참여 조건을 설정합니다. 예상 기본 경비는 항공·숙박·기본 식비 등을 포함한 1인 기준 금액으로 입력하며, 투자금은 제외합니다.
투자 포함 여부를 선택하고, 포함하는 경우 안정·균형·공격 중 희망 투자 스타일을 표시합니다. 모임 상세란에는 여행 콘셉트와 원하는 활동, 운영 방식 등을 자유롭게 작성합니다.

② 참여자 — 조건 비교 및 참가 신청
참여자는 목적지·여행일·예산·모임 조건·투자 여부로 모집 중인 팟을 탐색합니다. 목록에서 핵심 조건과 모집 현황을 비교하고, 상세 내용을 확인한 뒤 참가를 신청합니다.
이를 통해 여행 취향뿐 아니라 예산과 투자에 대한 기대까지 미리 맞춰, 모임 구성 후 발생할 수 있는 의견 차이를 줄입니다. 모집 단계의 투자 스타일은 희망 방향이며, 실제 투자 상품과 금액은 모임 구성 후 별도로 합의합니다.
참고로 반드시 포함되어야할 기능은 아래와 같습니다.
모임을 생성하고 가입한다.
- 모임 정보 생성 (참여 조건 설정 가능 항목)
  - 목적지(국가, 도시 또는 공항)
  - 여행일, 모집 인원, 참가 조건(성별·연령대·본인인증), 투자 성향, 상세 내용(모임장이 자유롭게 작성하는 영역)
- 조율 기준 설정
  - 승인 기준(승인 기준이란, 이 서비스의 사용자는 그룹단위로 사용하므로 의사결정을 진행할 때 투표와 같은 행동이 들어가게 되는데 이 때, 승인을 할 기준은 무엇인가?에 대한 설정입니다. 일반적으로는 승인을 위해 필요한 사람 수 정도로 생각하면 될 것 같아요.)
- 예치금(노쇼방지) 설정
