# 화면용 이미지

원본은 상위 폴더에 보존하고, 화면에서는 이 폴더의 파일만 사용합니다.

- 여행지 사진 6종: 최대 너비 1080px, JPEG 품질 78. 카드와 상세가 같은 파일을 공유합니다.
- 비행기: 최대 변 420px, 투명 PNG (최대 표시 140dp의 3배).
- 투자 성향 3종: 336×336px, 투명 PNG (112dp의 3배).
- 헤더 로고: 128×128px, 투명 PNG. 앱 아이콘/파비콘은 기존 원본을 사용합니다.

기존 로컬 이미지 6종은 6,000,075바이트에서 565,434바이트로 약 90.6% 줄었습니다. 여행지 사진까지 모두 앱 번들에 포함하므로 화면에서 Unsplash에 요청하지 않습니다. 개발용 Expo Go에서는 최초 실행 시 개발 서버의 에셋을 다운로드하므로 LAN 속도의 영향을 받을 수 있습니다.

여행지 사진은 기존에 사용한 동일한 Unsplash 사진을 아래 설정으로 내려받았습니다.
`https://images.unsplash.com/<photo-id>?w=1080&fit=crop&fm=jpg&q=78`

로컬 원본은 macOS `sips -Z <최대변> <원본> --out <출력>`으로 축소했습니다. LA 사진은 추가로 `-s format jpeg -s formatOptions 78`을 적용했습니다. 투명도를 유지하기 위해 일러스트는 PNG를 사용합니다.
