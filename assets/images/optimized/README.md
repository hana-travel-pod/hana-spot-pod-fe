# 투자 화면용 경량 이미지

화면은 이 폴더의 이미지 7종만 사용합니다. 큰 원본은 편집용으로 유지하고 화면 번들에 참조하지 않습니다.

| mascot-success.jpg | 348 | JPEG 품질 72 | 18,235 |
| request-mascot.png | 348 | 투명 PNG | 64,880 |
| samsung.png | 162 | 투명 PNG | 8,937 |
| skhynix.png | 108 | 투명 PNG | 4,363 |
| naver.png | 162 | 투명 PNG | 5,459 |
| hyundai.png | 162 | 투명 PNG | 6,748 |

기존 합계 2,237,685바이트 → 200,395바이트 (91.0% 감소).

마스코트는 최대 표시 높이 140dp의 3배, 팝업은 116dp의 3배, 로고는 최대 표시 너비 54dp의 3배를 기준으로 했습니다. 이미 작은 SK하이닉스 로고는 확대하지 않았습니다. 투명 배경은 PNG로 보존하고 흰색 배경의 성공 마스코트만 JPEG로 변환했습니다.

macOS `sips -Z <최대변> <원본> --out <출력>`으로 축소했습니다. 성공 마스코트는 `-s format jpeg -s formatOptions 72`를 추가했습니다.

`src/images.ts`에서 소스를 공유하고, 글꼴 로딩과 동시에 최초 화면 이미지를 우선하여 최대 3개씩 비동기 prefetch합니다. 이미지 실패가 화면 진입을 막지 않습니다. Expo Go 최초 실행 시에는 개발 서버로부터 에셋을 받아야 하므로 Wi-Fi/LAN의 영향을 받습니다. 실제 모바일 로딩 시간은 별도 기기 측정이 필요합니다.
