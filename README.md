# hana spot pod

React Native + Expo + TypeScript로 만든 모바일 여행 팟 프로토타입입니다. `reference/01.png`, `reference/02.png`의 하나 그린, 밝은 배경과 둥근 카드 구성을 참고했습니다.

## 실행

```sh
npm install
npx expo start --go --lan
```

Expo CLI의 QR 코드를 현재 프로젝트 SDK와 호환되는 Expo Go로 스캔합니다. iOS 시뮬레이터는 `npm run ios`, Android 에뮬레이터는 `npm run android`, 브라우저 미리보기는 `npm run web`으로 실행합니다.

### 휴대폰에서 테스트

1. 휴대폰에 프로젝트의 **SDK 57과 호환되는 Expo Go**를 설치합니다.
2. 컴퓨터와 휴대폰을 같은 Wi-Fi에 연결합니다.
3. 프로젝트 폴더에서 `npx expo start --go --lan`을 실행합니다. `npm run mobile`도 같은 명령입니다.
4. 터미널의 QR 코드를 Android에서는 Expo Go의 QR 스캐너로, iPhone에서는 카메라 앱으로 스캔합니다.
5. iPhone에서 계정 관련 오류가 나오면 컴퓨터에서 `npx expo login`을 실행하고, 휴대폰의 Expo Go에도 같은 Expo 계정으로 로그인합니다.

회사·공용 Wi-Fi에서 연결되지 않으면 `npx expo start --go --tunnel` 또는 `npm run mobile:tunnel`을 사용합니다. 터널은 인터넷 연결과 추가 터널 패키지 설치가 필요할 수 있습니다. Expo Go의 SDK가 맞지 않는다는 오류가 표시되면 [공식 SDK 호환성 안내](https://docs.expo.dev/troubleshooting/expo-go-version-mismatch/)를 확인합니다. iPhone은 App Store의 Expo Go와 프로젝트 SDK 조합에 따라 개발 빌드 또는 호환 Expo Go 배포가 필요할 수 있습니다.

참고: [Expo 공식 휴대폰 실행 안내](https://docs.expo.dev/get-started/start-developing/).

공식 Expo `blank-typescript` 템플릿을 기반으로 구성했으며 의존성 버전은 `package-lock.json`에 고정합니다. 환경 변수나 API 키는 필요하지 않습니다.

## 구현 범위

- 목적지·이름 검색, 지역 선택, 여행 기간·기본 경비·성별·연령·본인인증·투자 스타일 필터
- 팟 상세에서 여행 일정, 모집 현황, 참가 조건, 기본 경비, 희망 투자 방향, 투표 승인 인원, 노쇼 방지 예치금 확인
- 3단계 팟 생성: 여행 계획 → 참여 조건 및 운영 약속 → 최종 확인
- 날짜·인원·기본 경비·예치금·승인 인원 검증
- 참가 조건 검사 후 **신청 즉시 자동 가입**, 모집 현황 갱신 및 중복 가입 차단
- 신청 메시지는 선택 사항이며 별도의 필수 동의 체크 없이 참가 확정 가능
- 내 팟에서 **전체 / 가입한 팟 / 만든 팟** 목록 확인, 가입한 팟은 최근 참가순 표시
- 내 정보의 **가입한 팟 숫자**를 눌러 참가가 확정된 목록으로 이동
- 시작·종료일은 입력 대신 달력에서 선택 및 선택 해제, 과거 날짜와 시작일 이전 종료일 선택 차단
- 팟 북마크, 내 팟 목록, 프로필 수정 및 데모 본인인증
- AsyncStorage에 팟·신청·가입·북마크·프로필 저장, 재실행 시 복원

모집 인원은 개설자를 포함합니다. 승인 인원은 모집 완료 후 의사결정 투표에서 필요한 찬성 인원입니다. 1인 기본 경비에는 항공·숙박·기본 식비를 포함하고 투자금과 예치금은 제외합니다. 실제 투자 상품과 금액, 예치금 납부·반환·취소 기준은 모임 구성 후 별도 합의하는 것으로 표시합니다.

### 선택 입력과 기본값

팟 생성 항목은 모두 선택 사항입니다. 비워 두면 팟 이름은 `함께 떠나는 여행`, 국가·목적지·일정·기본 경비는 `미정`으로 표시합니다. 모집 인원은 4명, 의사결정 승인 인원은 과반수(기본 3명), 예치금은 0원을 적용합니다. 성별·연령은 제한 없음, 본인인증은 선택, 투자 포함은 꺼짐이 기본입니다. 입력한 인원·금액·날짜가 잘못된 경우에는 검증합니다. 경비 또는 일정이 미정인 팟은 해당 예산·기간 필터를 적용했을 때 제외됩니다.

기존 기기에 저장된 승인 대기 신청도 참가 조건과 정원이 맞으면 자동 승인합니다. 이미 승인한 신청은 재실행해도 인원을 다시 증가시키지 않습니다. 조건 불일치·정원 초과·모집 종료로 자동 처리되지 않은 이전 신청은 내 팟의 전체 목록에서 확인하고 취소할 수 있습니다.

## 검증

```sh
npm run typecheck
npm test
npm run build:web
```

도메인 테스트 9개는 날짜, 선택 입력과 기본값, 참가 조건, 자동 가입과 이전 데이터 자동 승인, 모집 정원, 비용, 투표 정족수, 조합 필터 및 달력 계산을 확인합니다. 테스트 실행에는 Node.js 22.18 이상이 필요합니다.

웹 브라우저의 모바일 크기(390×844)에서 달력 날짜 선택과 종료일 범위 제한, 전체 미입력 팟 생성, 빈 메시지 신청 후 자동 가입 및 가입한 팟 목록을 확인했습니다. iOS·Android Metro 번들도 생성했습니다. 실제 휴대폰/시뮬레이터에서의 실행 검증은 별도로 필요합니다.

### 의존성 검사

2026-10-06 기준 `npm audit`에서 간접 의존성 관련 경고 23건(높음 16건, 보통 7건)이 보고되었습니다. 주요 원인은 Expo/Metro 도구 체인의 `braces`, `node-forge`, `xcode`의 `uuid`입니다. 호환 가능한 `npm audit fix`를 적용했지만 경고가 남았습니다. `--force`는 Expo 44로 변경하는 호환성 파괴를 제안하므로 적용하지 않았습니다. 실제 서비스 배포 전 패치 버전과 영향 범위를 다시 검토해야 합니다.

## 프로토타입 경계

서버와 연결하지 않았습니다. 데이터는 해당 기기/브라우저에만 저장되며 다른 사용자와 공유되지 않습니다. 로그인·실제 본인인증·결제·투자 실행·개설자의 수동 승인·투표 실행은 연결되지 않았습니다. 가입은 데모 목적에 맞게 자동 승인합니다. 여행 사진은 Unsplash 외부 이미지 URL을 사용하므로 인터넷 연결이 필요합니다.

```text
src/screens/             생성, 필터, 상세·신청, 프로필
tests/domain.test.ts     핵심 조건 검증
```
