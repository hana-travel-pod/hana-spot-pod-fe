# hana-spot-pod-fe

## 여행 자금 캘린더 독립 프로토타입

현재 브랜치는 `feat/04-travel-calendar`입니다. 기존 하나픽과 이체 승인 기능은 각각의 기존 브랜치와 원래 작업 폴더에 보존되어 있습니다. 이 앱은 여행 준비 시점의 독립 시연이며, 하나픽의 여행 중 현금화 완료 시점과 자금 상태를 공유하지 않습니다.

```bash
npm ci
npx expo start --go
npm run lint
npm run typecheck
npm run test:calendar
```

이 작업 폴더에서는 상위 프로젝트의 설치된 의존성을 사용할 수 있습니다. 별도 복제한 환경에서는 먼저 `npm ci`를 실행합니다. 웹은 `npx expo start --web`으로 실행합니다.

### 시연 동선

월별 캘린더 → 2026년 10월 13일 지출일 선택 → 파리의 특별한 저녁 상세 → 매도 준비일 10월 8일과 체결 가정 결제일 10월 13일 확인 → 상단 아이콘으로 리스트 전환 → 일정 등록 또는 수정 → 두 보기의 변경 내용 확인.

최초 내부 기준일은 2026-10-07입니다. 일반 화면에는 역할 전환, 날짜 조작, 주문 및 자금 상태 변경 버튼을 표시하지 않습니다. 영업일 자료 범위는 2026-10-01부터 2026-11-30까지입니다. 시연 휴장일은 2026-10-09이며 토요일과 일요일도 제외합니다. 전체 실제 시장 휴장일 목록은 아닙니다. 자료 범위를 벗어나거나 다른 상품이면 날짜를 확정하지 않습니다.

[한국거래소 ETF 결제제도](https://regulation.krx.co.kr/contents/RGL/03/03060102/RGL03060102.jsp)의 T+2를 국내 상장 ETF에만 적용한 시연 규칙입니다. 준비일에 체결했다고 가정한 예상 결제일과, 체결일을 기준으로 계산한 예상 결제일을 별도로 표시합니다. 예상 결제일은 실제 출금 가능일을 확정하지 않으며 출금 가능 상태는 자동으로 전환하지 않습니다.

추가 경험비 예시 자금 440,000원은 투자 중, 매도 후 결제 대기, 출금 가능 중 한 상태에만 배치합니다. 간결한 자금 요약은 선택 날짜의 일정 아래에 표시하며 예비비는 포함하지 않습니다. 출금 가능한 원화만 `/travelog` 환전·충전 시연으로 이동할 수 있습니다. 일정은 계획이며 등록 또는 삭제만으로 잔액을 차감하지 않습니다. 현재 사용 가능액과 계획 합계의 부족 금액을 따로 경고합니다.

일정, 알림의 읽음 및 배너 표시 여부, 예시 날짜와 자금 상태, 충전 내역과 외화 지갑은 Expo Go 호환 AsyncStorage에 저장합니다. 앱 재실행 시 복원하며 저장 키는 `hana-calendar-demo-v3`입니다. 실제 증권 거래, 계좌 조회, 원격 푸시, 환전·충전 연동은 없습니다.

### 숨겨진 시연 진입

메인 화면의 **여행 자금 캘린더 제목을 약 1초 길게 누르면** `/demo` 개발 전용 화면으로 이동합니다. 웹에서는 `/demo` 주소로도 열 수 있습니다. 현재 선택한 추가 경험비 일정을 기준으로 다음 단계를 진행합니다.

1. `매도 준비 알림 시점으로`: 계산된 준비일로 내부 날짜를 맞추고 상단 배너와 알림함 항목을 생성합니다. 같은 일정은 한 항목만 유지하며 수정 내용을 반영합니다.
2. 배너를 탭하여 상세 내용을 확인합니다. 기본 예시의 준비일은 10/8, 예상 결제 및 출금 가능일은 10/13입니다. 결제 당일 출금 가능으로 가정하는 **데모 계좌 규칙**이며 실제 출금일을 보장하지 않습니다.
3. 제목을 길게 눌러 개발 화면으로 돌아가 `매도 체결 시연`을 실행합니다. 예시 ETF 자금 전체 440,000원을 결제 대기로 설정합니다.
4. 개발 화면에서 `출금 가능일 확인 시연`을 실행합니다. T+2 날짜로 이동하고 사용 가능 여부를 확인한 것으로 명시적으로 가정합니다. 단순 날짜 변경이나 주문 제출로는 출금 가능이 되지 않습니다.
5. 상세 또는 자금 요약의 `트래블로그 환전·충전`에서 160,000원을 입력하고 최종 확인합니다. 1 EUR = 1,600원 고정 예시 환율로 100.00 EUR를 지갑에 추가하고 원화는 280,000원으로 줄어듭니다. 확정 전에는 차감하지 않으며 동일 확인 건을 재처리할 수 없습니다.

배너는 약 250ms 동안 내려오고 5.5초 후 사라집니다. 닫거나 사라져도 상단 알림함에서 다시 확인할 수 있습니다. 데모 초기화는 개발 화면 안에만 있습니다. 유로는 센트 단위로 저장하고 0.01유로 미만은 버리며 수수료는 없는 예시입니다.

### 검증

날짜 계산과 자금 상태는 `src/features/calendar/model.ts`, 공통 상태는 `CalendarProvider.tsx`에 있습니다. `node scripts/verify-calendar-model.cjs`는 주말과 휴장일, 날짜 자료 범위, 다른 상품, 중복 합산 방지, 주문/체결 분리와 상태 자동 전환 방지를 확인합니다.

`npx expo export --platform all --output-dir .expo/verification-export` 후 `node scripts/verify-calendar.cjs`는 Chrome에서 월 이동, 등록·수정·삭제, 리스트 동기화와 데모 흐름을 조작하여 확인합니다.

통화 변경 이전의 v2 엔화 데이터는 원본 저장 키를 보존합니다. 처음 v3으로 이동할 때 엔화 충전 시연에 사용했던 원화를 복원하고 유로 지갑과 충전 내역을 초기화합니다. 일정과 알림, 진행 단계는 유지하며 기본 예시 일정명만 파리로 변경합니다.
