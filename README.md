# hana-spot-pod-fe

## 모임 자금 이체 승인 프로토타입

`origin/main`에서 분기한 독립 Expo 앱입니다. 실행하면 이체 승인 화면으로 바로 진입합니다.
하나픽 추천 화면과 상태는 포함하지 않습니다. 추가 경험비 440,000원은 차감하지 않는 별도 자금 안내 값입니다.

```sh
npm ci
npm start
npm run lint
npm run typecheck
npm run test:transfer
```

현재 개발 worktree에서는 상위 프로젝트에 설치된 동일 버전의 의존성으로도 실행할 수 있습니다.
별도 clone에서는 `npm ci`로 의존성을 설치해 주세요.

녹화 순서: 모임장 요청 작성 → 요청 확인 → 본인 확인과 시연용 서명 → 참여자 1, 2, 3의 상세 확인과 서명 → 전원 승인 → 시연용 이체 완료.
거절 시 잔액을 유지하며, 데모 초기화로 반복 시연할 수 있습니다.

실제 은행 이체, 원격 알림, 금융기관 본인 인증이나 법적 전자서명은 연결하지 않았습니다.
