# 하나 트래블 팟

React Native + Expo + TypeScript로 만든 모바일 여행 팟 프로토타입입니다. `reference/01.png`, `reference/02.png`의 하나 그린, 밝은 배경과 둥근 카드 구성을 참고했습니다.

## 실행

```sh
npm install
npx expo start --go --lan
```

Expo CLI의 QR 코드를 현재 프로젝트 SDK와 호환되는 Expo Go로 스캔합니다. iOS 시뮬레이터는 `npm run ios`, Android 에뮬레이터는 `npm run android`, 브라우저 미리보기는 `npm run web`으로 실행합니다.

### 휴대폰에서 테스트

1. 휴대폰에 프로젝트의 **SDK 57과 호환되는 Expo Go**를 설치합니다.
2. 컴퓨터와 휴대폰을 같은 Wi-Fi에 연결합니다.
3. 프로젝트 폴더에서 `npx expo start --go --lan`을 실행합니다. `npm run mobile`도 같은 명령입니다.
4. 터미널의 QR 코드를 Android에서는 Expo Go의 QR 스캐너로, iPhone에서는 카메라 앱으로 스캔합니다.
5. iPhone에서 계정 관련 오류가 나오면 컴퓨터에서 `npx expo login`을 실행하고, 휴대폰의 Expo Go에도 같은 Expo 계정으로 로그인합니다.

회사·공용 Wi-Fi에서 연결되지 않으면 `npx expo start --go --tunnel` 또는 `npm run mobile:tunnel`을 사용합니다. 터널은 인터넷 연결과 추가 터널 패키지 설치가 필요할 수 있습니다. Expo Go의 SDK가 맞지 않는다는 오류가 표시되면 [공식 SDK 호환성 안내](https://docs.expo.dev/troubleshooting/expo-go-version-mismatch/)를 확인합니다. iPhone은 App Store의 Expo Go와 프로젝트 SDK 조합에 따라 개발 빌드 또는 호환 Expo Go 배포가 필요할 수 있습니다.

참고: [Expo 공식 휴대폰 실행 안내](https://docs.expo.dev/get-started/start-developing/).

공식 Expo `blank-typescript` 템플릿을 기반으로 구성했으며 의존성 버전은 `package-lock.json`에 고정합니다. 환경 변수나 API 키는 필요하지 않습니다.

## 구현 범위

- 목적지·이름 검색, 여행 기간·기본 경비·성별·연령·본인인증·투자 스타일 필터
- 팟 상세에서 여행 일정, 모집 현황, 참가 조건, 기본 경비, 희망 투자 방향, 투표 승인 인원, 노쇼 방지 예치금 확인
- 3단계 팟 생성: 여행 계획 → 참여 조건 및 운영 약속 → 최종 확인
- 날짜·인원·기본 경비·예치금·승인 인원 검증
- 참가 조건 검사 후 **신청 즉시 자동 가입**, 모집 현황 갱신 및 중복 가입 차단
- 신청 메시지는 선택 사항이며 별도의 필수 동의 체크 없이 참가 확정 가능
- 내 팟에서 **전체 / 가입한 팟 / 만든 팟** 목록 확인, 가입한 팟은 최근 참가순 표시
- 내 정보에서 여행 프로필 확인 및 수정
- 필터·팟 생성의 일정을 하나의 공통 달력에서 출발일·귀국일로 선택, 범위 강조와 박·일 표시 및 선택 해제, 팟 생성에서 과거 날짜 선택 차단
- 팟 북마크, 내 팟 목록, 프로필 수정 및 데모 본인인증
- AsyncStorage에 팟·신청·가입·북마크·프로필 저장, 재실행 시 복원

모집 인원은 개설자를 포함합니다. 승인 인원은 모집 완료 후 의사결정 투표에서 필요한 찬성 인원입니다. 1인 기본 경비에는 항공·숙박·기본 식비를 포함하고 투자금과 예치금은 제외합니다. 실제 투자 상품과 금액, 예치금 납부·반환·취소 기준은 모임 구성 후 별도 합의하는 것으로 표시합니다.

### 선택 입력과 기본값

팟 생성 항목은 모두 선택 사항입니다. 비워 두면 팟 이름은 `함께 떠나는 여행`, 국가·목적지·일정·기본 경비는 `미정`으로 표시합니다. 모집 인원은 4명, 의사결정 승인 인원은 과반수(기본 3명), 예치금은 0원을 적용합니다. 성별·연령은 제한 없음, 본인인증은 선택, 투자 포함은 꺼짐이 기본입니다. 입력한 인원·금액·날짜가 잘못된 경우에는 검증합니다. 경비 또는 일정이 미정인 팟은 해당 예산·기간 필터를 적용했을 때 제외됩니다.

기존 기기에 저장된 승인 대기 신청도 참가 조건과 정원이 맞으면 자동 승인합니다. 이미 승인한 신청은 재실행해도 인원을 다시 증가시키지 않습니다. 조건 불일치·정원 초과·모집 종료로 자동 처리되지 않은 이전 신청은 내 팟의 전체 목록에서 확인하고 취소할 수 있습니다.

## 검증

```sh
npm run typecheck
npm test
npm run build:web
```

도메인 테스트 17개는 날짜, 선택 입력과 기본값, 참가 조건, 자동 가입과 이전 데이터 자동 승인, 모집 정원, 비용, 투표 정족수, 조합 필터 및 달력 계산을 확인합니다. 테스트 실행에는 Node.js 22.18 이상이 필요합니다.

웹 브라우저의 모바일 크기(390×844)에서 달력 날짜 선택과 종료일 범위 제한, 전체 미입력 팟 생성, 빈 메시지 신청 후 자동 가입 및 가입한 팟 목록을 확인했습니다. iOS·Android Metro 번들도 생성했습니다. 실제 휴대폰/시뮬레이터에서의 실행 검증은 별도로 필요합니다.

## 프로토타입 경계

## 디자인 적용 기준

`docs/01_join/STYLE.md`의 색상, Hana2 Regular·Medium·Bold, 최대 화면 폭 430dp, 좌우 여백 22dp, 버튼 최소 높이 56dp 및 반경 12dp를 적용합니다. React Native의 숫자 레이아웃 단위는 dp로, 웹에서는 같은 숫자의 CSS px로 매핑합니다. 추천 카드는 단색 민트 배경과 반경 22dp, 패딩 20dp를 사용하며 그림자나 떠오르는 효과를 적용하지 않습니다.

가이드에 없는 보조 규격은 카드·섹션 제목 19dp, 작은 배지·탭 설명 13dp, 목록 카드 경비 18dp로 보완했습니다. 상세 화면의 핵심 금액은 38dp입니다. 내 정보에는 팟 관리 요약이나 프로토타입 안내 박스를 표시하지 않습니다.

필터의 여행 일정은 하나의 달력에서 출발일과 귀국일을 차례로 선택하고, 두 날짜를 모두 선택한 뒤 `일정 적용`으로 반영합니다. 앞선 날짜를 누르거나 선택 완료 후 새 날짜를 누르면 다시 출발일부터 선택합니다. 월을 넘긴 일정과 박·일 계산을 지원하며, 선택 해제와 필터 초기화로 일정을 지울 수 있습니다. 투자 성향 옵션은 전체 → 안정 → 균형 → 공격 → 없음 순이며, 성향을 선택하면 해당 설명과 `reference`의 아이콘을 표시합니다.

## 통합 목적지 및 승인 인원

팟 생성의 지역·국가·도시/공항 입력을 `여행 목적지` 검색창 하나로 통합했습니다. 한글·영문·공항 코드로 검색하고 국가/도시/공항 결과 중 하나를 선택합니다. 표시 이름 외에 `destinationSelection`의 고유 ID, 유형, 국가 ID, 도시 ID, 공항 코드를 저장합니다. 국가 유형은 국가 전체, 도시 유형은 등록된 해당 도시의 모든 공항, 공항 유형은 특정 공항 하나를 대상으로 합니다. 필터에서 넓은 범위와 좁은 범위가 겹치는 팟도 함께 표시합니다. 예를 들어 파리의 모든 공항을 선택한 팟은 CDG 또는 ORY 필터에도 포함되고, CDG만 선택한 팟은 ORY 필터에서 제외됩니다.

현재 서버나 목적지 API가 없어 로컬 카탈로그를 사용합니다. 지원 범위는 **6개 국가, 11개 도시, 16개 공항**입니다. 대한민국(서울·제주·부산), 일본(도쿄·오사카·교토), 프랑스(파리), 인도네시아(발리), 중국(베이징), 미국(텍사스 파리 / 로스앤젤레스)을 제공합니다. 파리는 `파리`, `Paris`, `프랑스 파리`, `France Paris`로 검색할 수 있으며 CDG·ORY·BVA를 포함합니다. 전 세계 도시나 모든 소규모 공항을 조회하는 API는 연결하지 않았습니다. `모든 공항`은 카탈로그의 도시별 연결을 사용하며 목록이 확장되면 해당 범위에도 함께 포함됩니다. 교토는 접근 공항으로 KIX·ITM에 연결합니다. 동일 이름의 파리는 프랑스 일드프랑스/미국 텍사스로 구분합니다.

자동완성은 180ms 지연 검색, 이전 요청 취소, 검색 중·결과 없음·오류/재시도 상태를 지원합니다. 방향키로 결과를 이동하고 Enter로 선택, Esc로 결과를 닫습니다. 선택하지 않은 검색어가 남으면 다음 단계나 필터 적용 전에 선택 또는 검색어 지우기를 요청합니다. 이미 선택한 목적지는 새 결과 선택으로 변경하거나 별도 삭제 버튼으로 지울 수 있습니다. 기존 저장 키와 데이터 버전은 유지하며 인식 가능한 국가/도시/공항에만 메타데이터를 연결하고, 모호하거나 지원되지 않는 기존 자유 입력은 그대로 보존합니다.

승인 인원은 1명부터 모집 전체 인원까지 1명 단위로 드래그해 선택합니다. 기본값은 과반수이며 모집 인원을 줄이면 이전 선택도 새로운 상한 이내로 제한됩니다. 웹은 네이티브 range 입력으로 방향키·Home·End를 지원하고 모바일은 터치 드래그 및 접근성 증가/감소 동작을 지원합니다.

카탈로그 참고 자료: [Paris Aéroport](https://www.parisaeroport.fr/en), [나리타 국제공항](https://www.narita-airport.jp/en/), [파리 보베 공항](https://www.aeroportparisbeauvais.com/en/passengers), [텍사스 파리 Cox Field](https://www.paristexas.gov/airport), [교토 접근 공항](https://www.japan.travel/en/destinations/kansai/kyoto/).

기본 더미 팟은 오사카 → 베이징 → 파리 → LA 순서의 4개입니다. 파리는 2026-11-20~2026-11-24, 4명 중 3명, 공격 성향으로 구성합니다. 이전 저장 데이터는 `demoRevision: 2`로 한 번 갱신하면서 기존 팟과 신청/저장을 비우고 4개로 교체하며, 프로필은 유지합니다. 이후 새로 만든 팟과 가입/저장은 계속 보존합니다. 목록 카드는 요청에 따라 2dp 테두리와 드롭 섀도, 26dp 간격을 적용하며 성별/연령 등의 선택 버튼은 1.5dp 테두리를 사용합니다. 로고와 앱 아이콘/웹 파비콘은 `reference/logo.png`를 사용합니다. 화면의 가운뎃점은 `/`로 바꾸되 이전 데이터의 목적지 검색은 기존 구분자도 인식합니다.

상세의 팟장 표시는 `닉네임 팟장` 순서입니다. 내 팟의 선택 버튼은 전체=민트, 가입한 팟=파랑, 만든 팟=보라로 구분하며 미선택 상태는 공통으로 유지합니다. 미국 팟 사진은 내장 imagegen으로 제작한 `assets/images/los-angeles.png`를 앱에 포함하며, 제작 프롬프트는 같은 경로의 `los-angeles.md`에 기록합니다. 저장된 미국 팟의 기존 사진도 앱 실행 시 새 사진으로 교체하되 인원, 가입, 북마크는 유지합니다. 신규 미국 팟에도 해당 사진을 적용합니다.


이미지 로딩 최적화: 여행지 사진 6종을 로컬 JPEG로 포함하고 헤더 로고, 비행기, 투자 성향 이미지를 표시 크기의 약 3배로 축소했습니다. `assets/images/optimized/README.md`에 해상도와 원본 출처를 기록합니다. 목록/상세는 같은 이미지 소스를 공유하고, 네이티브 앱 시작 시 내장 이미지를 백그라운드에서 최대 3개씩 미리 불러옵니다. 기존 저장된 Unsplash 사진 주소도 로컬 이미지로 연결하며 가입 및 저장 상태를 유지합니다. Android 기본 이미지 페이드 시간을 제거했습니다. 실제 기기에서의 로딩 시간은 기기 및 Expo 개발 서버 연결 상태에 따라 달라집니다.


모바일 팝업 레이아웃: `Sheet` 내부에 별도의 `SafeAreaProvider`를 두어 iOS 모달의 독립된 네이티브 뷰에서도 노치/홈 인디케이터 여백을 계산합니다. 팟 만들기, 필터, 프로필, 상세 및 중첩 일정 선택에 공통 적용합니다. 전체 화면 모달에서 제목/하단 버튼은 축소하지 않고 본문만 스크롤하며, 작은 화면에서는 헤더와 버튼 영역의 여백을 줄입니다. 브라우저에서 320×568, 390×844, 430×932 크기와 중첩 일정 팝업을 확인했습니다. iOS 기기 노치와 소프트 키보드의 실제 동작은 기기 검증이 필요합니다.


시연 데이터 초기화(개발자 숨김 기능): **내 정보 또는 여행 프로필 수정 화면의 큰 사용자 아이콘을 한 번 누르고, 확인창에서 초기화를 선택합니다.** 생성한 팟/가입/저장/프로필을 초기 더미 팟 4개와 김하나 프로필로 되돌리고 탐색 첫 화면으로 이동합니다. `hana-spot-pod:v1` 저장 키만 삭제하며 다른 앱 데이터에는 영향을 주지 않습니다. 대기 중인 저장이 완료된 후 초기화하고 초기화 중 새 저장과 중복 초기화를 차단합니다. 실패하면 현재 데이터를 유지하고 오류 안내를 표시합니다.
