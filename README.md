# hana spot pod

React Native + Expo + TypeScript 기반의 공동 투자안 투표 모바일 프로토타입입니다. 저장소에 앱 소스와 패키지 설정이 없어 설치된 Expo SDK 57 패키지로 최소 앱 구조를 복원했습니다. 추가 라이브러리는 설치하지 않았습니다.

## 실행

```sh
npm install
npm start
```

프로젝트 SDK를 지원하는 Expo Go로 터미널 QR을 스캔합니다. 같은 네트워크에서 실행해주세요. `npm run ios`, `npm run android`는 시뮬레이터/에뮬레이터, `npm run web`은 웹 미리보기입니다.

## 화면과 흐름

1. **투자안 선택**: 마스코트 안내에서 모임의 투자 성향과 의미를 확인합니다. AI 추천 ETF 최대 3개와 모임원이 제안한 개별 주식 4개를 별도 영역으로 표시합니다. 두 영역에서 복수 선택 가능하며 상세 방문 후에도 선택이 유지됩니다. 생성 버튼은 준비 중 안내를 표시합니다.
2. **투자안 상세**: ETF는 기초지수/총보수/운용사, 주식은 종목 코드/시장/업종/제안한 회원을 표시합니다. 추천 이유, 특징, 투표 현황을 확인하고 선택을 변경할 수 있습니다.
3. **투표 결과**: 별도 후보 목록과 요약 없이 전체 종목의 찬성 인원을 6칸 그래프로 비교합니다. 한 칸은 찬성 한 명이고 점선은 후보 등록 기준입니다. 대표자는 확정된 종목의 그래프 행에 있는 체크박스로 투자 확인 대상을 선택합니다. 일반 회원에게는 체크박스 및 진행 버튼이 표시되지 않습니다.
4. **투자 확인**: 모임 정보, 선택한 투자 후보, 후보 등록 근거를 확인합니다. 맨 아래에 투자 예정 금액 400,000원을 크게 표시합니다. 선택 변경으로 돌아갈 수 있습니다. 투자 실행 요청하기 버튼은 배경 음영이 있는 확인 팝업을 열고, 알림 보내기 / 취소를 선택할 수 있습니다. 알림 전송은 화면 내 목 동작이며 실제 푸시 알림이나 주문은 전송하지 않습니다.

대표 색상은 `#008485`입니다. 민트색은 배경과 후보 확정, 앰버색은 논의 중, 회색은 관심 낮음 표시에 사용합니다. Hana 폰트, 단색 카드, 상단 하나 로고, 점선으로 연결된 단계 표시를 사용합니다. 모든 화면의 가운데 점은 `/`로 대체했습니다. 상세/투자 확인에서도 큰 찬성 인원 숫자를 공유합니다. 마스코트와 제작 프롬프트는 `assets/images/mascot-hd.png`, `assets/images/mascot-prompt.md`에 있습니다.

## 데이터와 기본값

`src/domain.ts`에서 정책, 목 데이터, 타입, 표 집계 및 후보 상태를 관리합니다.

- `InvestmentPlan`: ETF/주식을 구분하는 타입과 AI/모임원 제안 출처. 주식에는 제안한 회원 ID가 있습니다.
- `POD`: 회원 6명, 균형 성향, 통과 기준 3명, 투자 예정 금액 400,000원. `STYLE_DESCRIPTIONS`에 성향별 설명을 분리했습니다.
- `DEMO_CONFIG.currentMemberId`: 대표자 김하나(`m1`). 역할은 `POD.members`에서 변경합니다.
- `DEMO_RULES`: 선택 개수 제한 없음, 최소 1개 제출, 제출 후 수정 불가, 후보 복수 선택, AI 추천 최대 3개.
- `AI_PLANS`: 미국 S&P500, 국내 국채 3년, 글로벌 배당 우량주 ETF 예시.
- `STOCK_PLANS`: 삼성전자, SK하이닉스, NAVER, 현대자동차. 제안 이유와 투표는 목 데이터입니다. 주가나 실시간 금융 데이터는 사용하지 않습니다.
- `INITIAL_VOTES`: 회원별 고유 투표. 초기 표는 위 종목 순서대로 4/2/1/4/2/2/0명입니다. 표 수는 유효한 회원 ID의 고유 인원수로 집계합니다.
- `DemoState`: 회원별 표, 현재 회원 선택, 제출 여부, 투자 확인 대상, 마지막으로 수신한 목 투표. 앱 실행 중 메모리에만 유지됩니다.

### 투표 현황 표시

첫 화면에 전체 상태 요약과 종목별 큰 찬성 인원을 표시합니다. 표 수에서 상태를 계산하므로 목록/상세/결과/투자 확인이 항상 같은 값을 사용합니다.

- **후보 확정**: 통과 기준 3명을 초과한 4명 이상. 하나 컬러 배지와 강조 카드.
- **논의 중**: 기준 충족 인원의 절반 이상, 현재 2~3명. 앰버 배지.
- **관심 낮음**: 현재 0~1명. 회색 배지.

후보 확정은 투자 후보 등록을 뜻하며 최종 승인이나 주문 실행이 아닙니다. 상태는 인기/표 수를 표시하며 실제 투자 전망을 평가하지 않습니다.

목 투표의 자동 추가는 꺼져 있습니다 (`DEMO_RULES.simulateLiveVotes: false`). 시간이 지나도 득표수가 늘어나지 않으며 현재 회원이 투표를 제출하면 선택한 종목에만 1표씩 반영됩니다. 서버나 WebSocket 연동은 없습니다.

자동 수신 데모가 필요하면 `simulateLiveVotes`를 `true`로 바꾸고 `liveVoteIntervalMs`에서 간격을 변경할 수 있습니다. 후보 없음 상태는 초기 투표를 비워 확인할 수 있습니다. 역할을 다른 미투표 회원으로 변경할 때는 해당 회원의 기존 목 투표를 제거하세요.

## 검증

```sh
npm run typecheck
npm test
npm run export
```

타입 검사 및 도메인 테스트 15개 통과. AI/주식 영역 구성, 회원/득표 정합성, 혼합 복수 선택, 기준 초과, 중복 제출/수신 방지, 후보 없음, 대표자 권한, 실시간 상태 갱신, 제출 후 선택 잠금, 자동 이벤트 후의 후보 분포를 검증합니다.

브라우저 모바일 크기에서 실시간 득표 갱신, ETF/주식 혼합 선택, 상세 왕복, 제출, 후보 선택 및 투자 확인 흐름을 확인했습니다. Android/iOS/Web 번들 출력 위치는 `/tmp/hana-spot-pod-export`입니다. 실제 iOS/Android 기기의 Expo Go 실행은 아직 확인하지 않았습니다.

AI/추천 이유/투표는 목 데이터입니다. 서버, 영구 저장, 금융 API, 주문, 결제, 자금 이동, 종목별 비중 설정은 포함하지 않습니다.
